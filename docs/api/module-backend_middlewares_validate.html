Module: backend/middlewares/validate

(require("backend/middlewares/validate"))(schema, propertyopt) → {ExpressHandler}

Valide `req[property]` avec un schéma Joi. Les champs inconnus sont supprimés (ex. un `price` envoyé par le client) et les valeurs sont normalisées.
